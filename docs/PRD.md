# Knode - product

Knode is your second brain for AI: one local memory that is yours, that every AI agent you use can
read and add to, and that you see and organise in a native app.

## The problem

What you work out with AI agents is scattered across chats and tools; some agents delete their
history after a while, and each one only remembers its own. Notes live in other apps. Built-in
memories are closed and stay inside one product.

## What Knode does

- **One memory for every agent:** Claude Code, Codex, Gemini and Claude Desktop read and write the
  same memory through MCP.
- **Everything together:** notes, ideas, decisions and every conversation, connected as nodes and links.
- **Spaces with permissions:** each space is a `.knode` file; you choose which agent sees which space
  and whether it can write.
- **Local and open:** your files, on your Mac, in an open format. No AI inside the app: the agent is
  the AI, Knode is its memory.

## Who it is for

People who work with AI agents every day. The first user is the person building it.
